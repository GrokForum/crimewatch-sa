# CrimeWatch SA pipeline

Ingests the official SAPS quarterly crime workbook, writes official-derived CSVs, runs data-quality and POPIA gates, and builds a static DRAFT site.

- `fetch_official.py` downloads an official file listed in `data/manifest.json` over HTTPS, verified against the reviewed CA bundle `ci/certs/saps-chain.pem` (the SAPS site sends only its leaf certificate; verification is never disabled). A certificate/TLS error prints a GitHub Actions `::error` annotation and a `FAIL` line on stderr, appends a JSON line to `logs/collector.log`, and exits 2; any other download failure is logged the same way and exits 1. The workbook is then checked against its size and sha256 pin.
- `verify_workbook.py` checks the workbook against the pin. A missing, invalid or incomplete manifest stops with a plain `FAIL` message, not a traceback. The pin is bumped only by a reviewed change.
- `ingest_saps_xlsx.py` reads the RAW Data sheet and writes `data/saps_q2_2026_27_long.csv`, `data/stations_q2_2026_27_layers.csv` and `data/districts_q2_2026_27_layers.csv` (the workbook's own police-district rows). Blank or non-numeric count cells are a hard failure; they are not filled with zero.
- `dq_check.py` compares workbook totals with figures typed from the official PDF (`expected_pdf_q2_2026_27.json`, with PDF page numbers), then runs the district gate: district sums must equal the national totals, and any district whose row differs from the sum of its station rows must be listed in `known_district_disputed` (printed as DISPUTED); an unlisted one fails. Malformed values fail with a plain message.
- `popia_gate.py` checks every CSV under `data/` against a reviewed column allowlist with pinned constants, bans free-text columns, scans for identity-number, phone and email patterns, and allows only the province name on boundary features. A new file without an allowlist, including any future incident-level file, fails closed.
- `site_content.py` holds the reviewed public text: headline figures, high-profile entries, the media-vs-official rows, method text and the source register. Every figure carries one of the five fact labels and at least one source from the register.
- `build_site.py` builds `build/site/` deterministically (no timestamps): home, heat map, high-profile, media-gap, daily-sweeps and method pages, `robots.txt` (`Disallow: /`) and a file manifest. Map data is a static script; the pages make no third-party requests.
- `sweeps.py` loads and validates `data/sweeps.json` (every fact has a reference; only official, police, media and public-figure handles are named on the page).
- `site_gate.py` is the POPIA and hygiene gate for the generated site (see the module docstring). Internal names are checked against `banned_terms.sha256`, which stores hashes only. An optional private names list can be given with `CW_PRIVATE_NAMES_FILE` (kept outside the repository); a missing path fails with a plain message and a non-zero exit, not a traceback. Emails are decoded (HTML entities and common obfuscation) before the scan; the approved privacy contact is privacy@grokforum.site. Indexing is a deploy-time opt-in (`CW_INDEXABLE=1` plus `CW_SITE_HOST=crimewatch.grokforum.site` only) and is never set in CI.
- `tests/` is a pytest suite. From the repository root: `python -m pytest -q`.

Station and district layers: gangs, political and farm are explicit nulls (no official station series in this release), not zero. The CSVs are aggregates at police-station or higher levels and do not name private people. `note`, `period`, `source_url` and `source_note` columns are pinned constants, not free-text fields.

Province rates per 100,000 are arithmetic: the official count divided by the provincial population printed on slide 21 of the same pack. For murder and rape they reproduce the official ratios (tested). No district-level rate is calculated: no official district population series was found.
