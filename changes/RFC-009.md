## Goal

Add one plain footer link on every built public HTML page, including the generated 404 page, to the Watch directory at `https://watch.grokforum.site/`. This is a surgical chrome change only.

## Exact files

- `pipeline/build_site.py` — in `page()`, append one footer paragraph after the existing footer content (fact labels, repository, privacy contact and disclaimer stay as they are).
- `pipeline/site_content.py` — add the exact URL `https://watch.grokforum.site/` to the reviewed source register `SOURCES` (key `watch_directory`, kind “Watch directory”, not a crime source). Without that entry the site gate fails closed.
- `pipeline/tests/test_site.py` — assert every built `*.html` file contains the exact href and the exact visible text, and that the register entry matches. Existing `test_every_page_is_draft_noindex` must still pass.
- `changes/RFC-009.md`, `STATUS.md` — this record and one STATUS row.

## Link spec

Visible text is exactly `Part of the Watch network — watch.grokforum.site` (Unicode em dash, U+2014). The href is exactly `https://watch.grokforum.site/` (https, host only, trailing slash, no path, query or fragment). The control is a plain `<a>`. No `target`, no tracking parameters, no button or script. `rel="noopener noreferrer"` is included because every other outbound footer link on this site already uses those attributes. The href is taken from the new `SOURCES` entry so the register and the rendered link cannot drift.
