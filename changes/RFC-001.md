## Goal

Add a first research pipeline to the private repository after the README-only base commit on `main`:

1. Ingest the official SAPS Q2 2026/27 workbook and emit official-derived aggregate CSVs.
2. Commit the official-derived station-layer CSV and the long-form CSV used by the data-quality gate.
3. Pin Python dependencies and a pytest suite.
4. Add a nightly GitHub Actions workflow that installs, downloads the official workbook from saps.gov.za, builds, runs pytest and the data-quality gate.
5. Record this change and leave it for review as a draft pull request. Do not merge.

## How success is proven

1. `python -m pytest -q` passes locally, including when the official workbook is absent (committed CSVs) and when it is present (ingest path).
2. `python pipeline/dq_check.py data/saps_q2_2026_27_long.csv` exits 0. Known Western Cape and Eastern Cape murder discrepancies are printed as disputed, not as failures.
3. A POPIA scan of every committed file finds no private victims, children, witnesses or suspects; no IDs, phones, or emails other than the publisher noreply address in git identity; no residential addresses; no keys or tokens. Station, district and province names are official SAPS geographic units.
4. A hygiene scan finds no staff or bot names and no absolute box paths in committed files.
5. Every commit uses the publisher identity: name "CrimeWatch SA publisher", email `noreply@crimewatch.grokforum.site`.
6. `git log --format='%an %ae %cn %ce'` shows only that identity.
7. The pre-review scanner (`review_kit.py`) is run against this head and its output is pasted into the draft pull request.
